
# Dynamic Pricing Strategy in Ride-Hailing

## Objective

Determine the surge pricing threshold at which revenue gains begin to erode customer satisfaction, ride completion, and long-term enterprise value.

## Dataset

* 50,000 ride records
* Mumbai, Bangalore, Delhi

## Key Findings

* Revenue Growth: +103%
* Contribution Margin Growth: +423%
* Customer Satisfaction: -43%
* Elasticity: -0.24
* LTV/CAC: 1.5 → 6.28

## Recommendation

Implement Retention-Focused Loyalty Protection to balance profitability, customer experience, and long-term enterprise value.
